口径

        
    
          
  • C 是请求到来前的既有上下文；E 是本轮新增 token；最终长度为 C+E。
    • 
          
  • 命中 token 按块向下取整。q 把“前缀命中”和“确实从 CMX 远程读取”分开。
    • 
          
  • a 是写入 CMX 的新状态比例；它不是 gateway 准入率。
    • 
          
  • GPU-saturated 用 unique-token 吞吐反推 λ；U=0 时必须使用外部 λ。
    • 
          
  • via-CMX 增加一次完整 Decode 读；direct 使用单独链路预算；local 无额外 handoff。
    • 
          
  • V4 SWA/MTP/compressor 与 K3 KDA 都是可移交 component；不同 compressor policy 是不同表示。
    • 
          
  • logical payload、engine entry payload、engine pages 和 custom wire 是不同口径。
    • 
          
  • Engine page 目前只对审计过的 V4 vLLM base-ring profile 给结果；N/A 表示合同未知，不回退成 payload。
