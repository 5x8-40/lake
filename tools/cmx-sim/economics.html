              Provider
              官方口径
              mempko 100K-prefix 实测
              规划语义
            

          
          
            

              Anthropic
              默认 5m；可选 1h
              5–6m 断崖
              5m 是合同；4m keepalive 是该实验策略
            

            

              OpenAI
              旧模型 in-memory 通常 5–10m、最长 1h；另有 extended / 新模型策略
              GPT-5.1：20m 约半数，30m 全冷
              特定模型/时点观测，不能概括当前全部 GPT
            

            

              DeepSeek
              Best-effort；官方称闲置后通常数小时至数天清理
              V3.2 在 10m 全冷
              相互冲突；只能记路径实测，不能写成 10m TTL
            

            

              Google Gemini
              Implicit 无 TTL 保证；explicit 默认 1h
              33%–83% 随机波动
              实验针对 implicit，不能外推 explicit cache
            

          
        

      


      

        
100 GB File Library ≠ KV quota

        

          OpenAI Help Center 当前写明 ChatGPT Pro 用户有 100 GB File Library storage。
          该额度用于上传和生成文件，不是 prompt cache、KV cache、GPU-local cache 或 CMX quota，不用于 KV sizing。
