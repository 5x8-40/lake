边界

        
    
          
  • 窗口开始时，每个 retained user 已有一段可命中的热缓存。
    • 
          
  • 窗口内不驱逐、不覆盖；所有新算 growing KV 保留到窗口结束。
    • 
          
  • 每用户只保留一份最新 continuation state，不按请求重复累计。
    • 
          
  • 不同用户之间不去重；若多个用户共享系统前缀，结果会偏高。
    • 
          
  • 未计 allocator 碎片、元数据、介质格式和后台整理余量。
    • 
          
  • 若 `U=0`，GPU 无 unique token 可计算，GPU 满载 req/s 无定义。
    •
